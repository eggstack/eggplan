# Eggplan Subsystem Roadmaps

Subsystem roadmaps translate the canonical specification into coherent,
dependency-aware workstreams. They are not direct coding-agent checklists.

A subsystem roadmap must define ownership, invariants, capabilities,
infrastructure, non-goals, current state, target architecture, dependency
graph, milestones, cross-cutting requirements, verification, risks, and
completion criteria.

Commit-specific file edits belong in plans/implementation/.
